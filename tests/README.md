# 端到端回归测试

`e2e_regression.js` 用 Playwright 对线上门户做一次完整回归：注册临时账号 → 逐功能验证 → 截图 → 清理账号。所有断言写入 `tests/screenshots/<时间戳>_report.json`，截图同目录。

## 运行

```bash
# 依赖：Playwright（用本机已安装的 node_modules）
NODE_PATH=<path-to-node_modules> node tests/e2e_regression.js
```

可选环境变量：

| 变量 | 说明 |
| --- | --- |
| `BASE_URL` | 门户地址，默认 `http://localhost:8899`；线上运行设为实际地址 |
| `ZIWEI_ADMIN_KEY` | 管理员口令。**仅运行时注入，绝不入库**。提供则测试管理员登录并在结束后自动删除临时账号；不提供则跳过管理员登录，仅验证入口存在 |

临时账号名/密码每次随机生成（`e2e_<时间戳>`），测试结束自动清理；若中途异常退出，可在服务器用管理员接口删除残留的 `e2e_*` 账号。

## 覆盖点（26 项断言）

| 模块 | 验证内容 |
| --- | --- |
| 首页 | 品牌 ∞ 图标渲染、无前端 JS 报错 |
| 账号 | UI 注册临时账号并登录；账号设置文案为「用户名/密码」（无「昵称/口令」） |
| 八字 | 档案自动排盘；AI 解读；**切到别的功能页后解读在后台继续并完成**；追问；**免责声明仅出现一次**；切页后提问框内容保留 |
| 梅花 | 起卦 → AI 解卦 |
| 紫微 | 档案自动排盘；命格视图 AI 解读；追问 |
| 塔罗 | 写问题 → 抽牌 → AI 解读 |
| 黄历 | 日历/历注加载 → AI 择日答疑 |
| 个人中心 | 历史卡**上下滚动（纵向）**；标题右侧**按日期查找**点击弹出与出生日期同款日历；历史详情追问条**与 AI 解读同款格式**（小字灰色备注） |
| 管理员 | 管理入口；口令登录；用户管理；运行日志；**看不到任何对话内容** |

## 完成信号

AI 解读卡流结束时由前端加 `.done` 类（后端已在正文后统一附加免责并计入落盘，前端不再追加第二条声明）。测试据此判定解读完成，比等待文本关键字更稳定。
