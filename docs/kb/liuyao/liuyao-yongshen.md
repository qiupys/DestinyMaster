# 用神：把问题对应到具体的爻

用神是一卦中代表所问之事的那个爻。六爻断卦的第一步不是看吉凶，而是先「取用神」——把现实问题准确对应到卦中的某一爻，之后所有的旺衰、生克、动静分析才有落点。取错用神，后面全错。

## 六亲为类象基础

用神取自六亲（父母、兄弟、子孙、妻财、官鬼），以卦宫五行为「我」推得：

- **父母**：长辈、文书、合同、房屋、学业、证件、庇护、辛劳。
- **兄弟**：兄弟姐妹、朋友、同事、竞争者、劫财、分夺。
- **子孙**：子女、晚辈、娱乐、悠闲、福气、解忧、医药（克官鬼）。
- **妻财**：钱财、资产、妻子/女友（男测）、客户、资源、价值。
- **官鬼**：职位、工作、丈夫/男友（女测）、官司、疾病、压力、鬼神。
- **世爻**：自己；**应爻**：对方、外部环境、事情的对立面。

## 分事项取用

- **问工作求职**：官鬼为用神（职位）；父母为文书合同；世爻为自己。
- **问财运投资**：妻财为用神；子孙为财源（生财）；兄弟为劫财（忌）。
- **问感情婚姻**：男测以妻财为用神，女测以官鬼为用神；世应看双方关系。
- **问官司诉讼**：官鬼为用神；父母为证据文书；世应为原被告。
- **问疾病健康**：官鬼为病；子孙为医药（子孙持世或动则吉）；父母为药方。
- **问学业考试**：父母为用神（文书）；官鬼为功名。
- **问出行迁移**：世爻为出行人；父母为舟车住处；应爻为目的地。

## 取用原则

- 用神须「有根」——得月建日辰生扶、或临世应、或发动，才有力量；空亡、月破、伏藏则无力。
- 用神唯一时直取；卦中两现时，取发动者、临世应者、得月建日辰者。
- 用神不上卦（伏藏）时看伏神与飞神关系，待引拔之时显现。
- 世爻永远是「自己」的基准——任何问题都要看用神与世爻的生克关系（用神生世吉、克世凶、与世比和看旺衰）。

用神定准后，再谈动变、月建日辰、旬空与应期，结论才能回到具体爻位核对。
