# 动爻与变卦：事情如何变化

六爻以「动」表示事情的变动之处。静爻只是现状，动爻才是变化的枢纽——解卦的重心永远落在动爻上。

## 老阴老阳为动

六爻以四象记爻：

- **少阳（七）**：阳爻静，不变。
- **少阴（八）**：阴爻静，不变。
- **老阳（九）**：阳爻动，将变阴。
- **老阴（六）**：阴爻动，将变阳。

老阴老阳又称「动爻」「变爻」，是本卦转向变卦的关键。传统以○记老阳、×记老阴。

## 本卦与变卦

- **本卦**：起卦当下得到的卦，代表事情当前的状态与背景。
- **变卦**：动爻阴阳翻转后得到的新卦，代表事情变化后的结果走向。

无动爻时称「静卦」——六爻皆静、无变卦，这是正常的起卦结果，主事情维持现状、暂无变化。静卦并非缺漏，解卦时只看本卦各爻与月建日辰。

有多个动爻时，变化层次更复杂：动爻之间生克、是否形成合冲、变卦是否又回头克本卦，都要逐一核对。

## 动爻的解读要点

- 动爻是事情「动的那个点」——它往往对应问题的核心变量。
- 动爻所临的六亲，指出是哪类人事在变动（如妻财动主钱财或感情对象，官鬼动主工作或压力）。
- 动爻变出的爻（变爻）若回头克动爻，称「回头克」，主变化反噬、事与愿违；变爻生动爻则助力。
- 动爻与静爻的「合」：动而遇合则被牵绊，冲开之时才是应期。

## 用神动静

用神发动，主所问之事本身在动、有转机；用神静而受动爻冲克，主被动受冲击。用神的动静与月建日辰旺衰合看，是判断吉凶成败的核心。
