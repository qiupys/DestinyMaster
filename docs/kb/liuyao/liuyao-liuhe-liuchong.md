# 卦的变化形态：合冲、反伏、进退

除了单爻的旺衰动变，六爻还看整个卦或动变关系的形态。这些形态描述事情「是聚是散、是反复还是递进」。

## 六合与六冲

- **六合卦**：初爻与上爻、二与五、三与四的地支两两相合，主事情和合、团聚、易成、拖延（合住）。
- **六冲卦**：对应爻位地支两两相冲，主事情散、冲突、难聚、速决。八纯卦（乾坎艮震巽离坤兑）与部分卦为六冲。
- 动爻逢合为「合待冲开」——当下被牵制，冲开之时发动；逢冲为「冲动」，事情加速但易反复。

用神临六合主事情有凝聚、需等待；临六冲主事情易散、进展急。合与冲不可单独定吉凶，须结合用神旺衰。

## 反吟与伏吟

- **反吟**：变卦地支与本卦相反（如发动爻变出的支冲原支），主事情反复、来回、反复无常、事难安稳。内外反吟又分：内反吟多家庭内部反复，外反吟多外部环境反复。
- **伏吟**：变卦地支与本卦相同（动而支不变，或卦形重复），主事情停滞、呻吟、拖延、进退两难、旧事重提。

反吟伏吟多主不吉或迟滞，但若是忌神伏吟反吟，反而有限制其负面作用的一面——须看是何六亲。

## 进神与退神

- **进神**：动爻变出的地支五行前进（如亥动化子、卯动化辰），主事情进展、增长、步步推进。
- **退神**：动爻变出的地支五行后退（如子动化亥、辰动化卯），主事情退步、消减、回落。

用神化进神吉（得势渐长），忌神化进神凶；用神化退神则不济，忌神化退神则忧患渐消。

## 游魂与归魂

按八宫卦变，世爻位置决定卦的归属形态：

- **游魂卦**：世在第四爻，主心神不定、外出、漂泊、事情未定、远行、游离。
- **归魂卦**：世在第三爻，主事情回归、归家、旧事重现、心有所归、迟滞待定。

游魂多主不稳定与远行，归魂多主回归与终结。二者与用神动静合看，可判断事情是「向外浮动」还是「向内收束」。

## 综合

六合/六冲定聚散，反吟/伏吟定反复或停滞，进退神定趋势方向，游魂/归魂定心志归属。这些是对用神旺衰动变的补充，不能脱离具体爻位与六亲单论吉凶。
