### 性格特征

正官是异性相克的关系，代表正当的权力、地位、名誉和责任。正官格的人通常具有强烈的责任感和正义感，适合从事管理、公务员等需要权威和信任的职业。

### 积极影响

- ✓ 事业运势较好，易获得上级赏识

- ✓ 社会地位稳定，声誉良好

- ✓ 具有管理才能和领导魅力

- ✓ 做事有条理，执行力强

### 消极影响

- ✗ 过于拘泥于规则，缺乏灵活性

- ✗ 压力较大，容易焦虑

- ✗ 可能过于看重外在评价

- ✗ 有时显得过于严肃

### 十神含义

代表权威、地位、责任心，象征正当的权力和社会地位。

## 十神在八字中的应用

十神分布在四柱中，每个位置都有其特定的含义和作用

### 四柱十神分布

日柱日干为日主，是分析十神的基准点

### 官星系统

正官代表正当权威、责任、地位；七杀代表压力、竞争、挑战。

### 印星系统

正印代表学问、权威、长辈助力；偏印代表偏门学问、宗教、玄学。

### 财星系统

正财代表正当收入、妻缘、稳定财富；偏财代表意外财、投资、人缘。
