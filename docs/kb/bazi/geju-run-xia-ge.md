## 润下格

### 格局定义

润下格是专旺格中的水气专旺格局。"润下"取自水的特性——润泽下流。

### 格局特点

润下格一旦成格，水气纯粹，主：

- • 智慧过人

- • 变通灵活

- • 深谋远虑

- • 财源广进

### 成格判断

日干为壬或癸，地支全为水（亥子丑三会或申子辰三合），月令得令（严格为亥子），天干无戊己土。
