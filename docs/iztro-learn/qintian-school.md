# 钦天门基础体系（钦天四化框架）

> 流派说明：钦天门以「四化」为唯一主轴论命，几乎不看杂曜神煞，强调河图洛书数理
> 与宫位体用。本文只收录该派公开流传的体系性概念框架，供四化相关问题时检索参断；
> 具体断诀与数理细则不在此展开，以免以讹传讹。

## 四化为用，宫位为体

钦天门认为：十二宫是「体」（人事的十二个领域），四化是「用」（能量在这些领域
间的流动）。论命即论四化在十二宫之间的流动轨迹——星曜只是四化的载体，
同一颗星在不同宫干引动下意义不同。

## 生年四化与来因宫

生年四化（禄权科忌）是命主先天带来的「定数」；而使生年四化成立的天干所在宫位，
称为「来因宫」——它是解读先天四化「为什么而来」的钥匙：来因宫指出了这份
福/权/名/债的源头。来因宫在六内宫（命兄弟夫妻子女财帛疾厄）与六外宫
（迁移仆役官禄田宅福德父母）意义不同：内为自身之事，外为他人与环境所予。

## 河图数理与宫位合参

钦天门以河图先天数理配十二宫：一六共宗（水）、二七同道（火）、三八为朋（木）、
四九为友（金）、五十同途（土）。命盘上相隔五位的宫位数理相通（如命宫与
财帛宫一六共宗之类，按具体排法），用于解释两宫之间先天的关联与相互成就/拖累。
此为该派数理层的基本思路，应用细则各传承表述不一。

## 化象与串联

四化落在宫位产生的「象」是钦天门的论事语言：

- 化禄：缘起、顺利、资源到位；
- 化权：强势、扩张、主导；
- 化科：贵人文书、平顺、显名；
- 化忌：执着、亏欠、收敛、结束。

「串联」指一条四化链：如 A 宫飞忌入 B 宫，B 宫的宫干又转化入 C 宫——
事象沿链路传递，链头是起因，链尾是归宿。论一件事常追 2~3 级串联才定轨迹。

## 忌的三种基本形态

- 生年忌：先天定数，此生功课所在；
- 飞宫忌：宫干飞出的忌，后天事象的引动；
- 自化忌：本宫天干使本宫星化忌，自我流失、不守。
论忌先分形态，再论入宫/冲宫：忌入为「留住」，忌冲为「掀翻」；
双忌叠宫为该宫领域重大耗损的信号。

## 论命次序（钦天门框架）

1. 找来因宫，明先天四化「因何而来」；
2. 看生年四化落于六内/六外，分自身之事与他人之事；
3. 以体用宫位配河图数理，看宫位间的先天关联；
4. 大限流年飞化串联，追事象因果与应期。
