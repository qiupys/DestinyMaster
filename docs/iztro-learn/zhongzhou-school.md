# 中州派基础体系（王亭之体系框架）

> 流派说明：中州派紫微斗数以「星系」为核心单位论命，主张先定星系架构、再论四化流曜。
> 本文只收录该派公开的体系性概念，供与三合派（本库古书篇）、飞星派（feixing-school）
> 对照参断；不编造具体断诀。

## 星系为主，四化为用

中州派论命的第一层不是单星，而是「星系」——以十四主星两两同宫构成的固定组合
（如紫微天府、太阳太阴、廉贞贪狼等）为单位判断性质。星系定「底盘」，四化只是
引动底盘变化的「用时之力」：同一星系，因四化飞临的宫位不同，应事方向不同，
但性质底盘不变。

## 借星安宫

某宫无主星（空宫）时，中州派的正规做法是「借对宫星系安宫参断」——借来的星系
力量打折扣、且需参酌对宫的牵引。借星后全盘十二宫的星系架构重新通盘考虑，
这正是「架构优先」的体现：先问宫里坐的是什么星系，再问吉凶。

## 星系组合与三方四正的层次

中州派看三方四正时强调层次：本宫星系为「体」，三方四正汇聚的星系为「用」；
先看对宫（影响最直接），再看三合方。宫位吉凶不是单星庙陷的加减，而是整个
星系网络合参的结果。

## 流曜与大限流年的叠法

论大限流年时，中州派重视原局星系与运限星系的「叠」：大限命宫叠在本命某宫，
两宫星系互涉；流年再叠一层。三层盘逐层引动，吉凶应期从「哪一层被引动」来判断。
流曜（流昌流曲、流魁流钺、流马等）只在该层起作用，力量小于原局四化。

## 四化的引动次序

中州派论四化强调「生年四化为定象，大限四化为引动，流年四化为应期」：
- 生年四化：定该宫领域的先天吉凶性质；
- 大限四化：十年内哪些宫位被引动、方向如何；
- 流年四化：当年的应事落点与时间。
三层四化叠在同一宫时（如双忌叠加），力量显著加重，是该年该宫的重点观察对象。

## 与其他流派的配合

中州派架构 + 三合派格局 + 飞星派轨迹，三者可互相校验：
- 先以星系定人格局性的强弱底色（中州）；
- 再以格局、庙陷定吉凶幅度（三合）；
- 最后以四化飞宫追因果与应期（飞星/中州四化叠法）。
