# 飞星派基础体系（四化飞宫框架）

> 流派说明：飞星派（又称河洛紫微斗数、梁氏飞星）以「四化飞宫」为核心推演工具，
> 与三合派侧重星曜组合、格局庙陷的取径互补。本文收录飞星派公认的体系性概念，
> 供检索时与三合派文献对照参断；具体宫位论断细则建议以三合派文献（本库古书篇）为主干，
> 飞星逻辑为经线串联。

## 四化飞宫的基本概念

飞星派认为：四化（禄、权、科、忌）是命盘能量流动的轨迹。生年四化由生年天干而定，
落在本命某宫（如化禄入夫妻宫），是「先天禀赋」；宫干飞出的四化（如夫妻宫的宫干又使
某星化忌）则是「后天变化的引动」。每一宫的天干都可以飞出四枚四化星，落入其他宫位，
构成宫与宫之间的因果链路。

## 生年四化归宫论

生年四化落在哪一宫，即该宫领域先天带有该化的性质：

- 生年禄落某宫：该宫领域先天有资源、顺遂、缘分厚，但「禄随忌走」——需看同宫或对宫
  忌的牵制；
- 生年权落某宫：该宫领域有掌控力、主见、开创性；
- 生年科落某宫：该宫领域有贵人、名声、文书之利，性质温和；
- 生年忌落某宫：该宫领域是命主此生「欠债」与「执着」所在，也是功课所在——
  忌入的宫位往往是人生最需要用心经营、也最容易受困的领域。

## 忌的五行属性与宫位关系

飞星派论忌，先看忌入何宫、再冲何宫（忌所在宫位的对宫为「冲宫」）。基本法则：
忌入某宫，力量作用于该宫本身；忌冲对宫，则冲击对宫的稳定。论断时常说
「忌入 A 宫冲 B 宫」，应事往往显现在 A、B 两宫的拉扯之间。

## 禄随忌走与忌随禄走

- 禄随忌走：禄是资源、诱因，忌是归属、结果。禄飞入某宫之后，最终去向要看忌落在
  何处——禄只是过程，忌才是终点。
- 忌随禄走：反之，追吉时先寻禄的落宫，再看忌是否承接。禄忌成对论，是飞星派
  追踪一件事「起因（禄）—结果（忌）」的基本手法。

## 自化

宫位的天干使本宫星曜化禄/化权/化科/化忌，称为「自化」：

- 自化禄：该宫之事物易来易去、不守；
- 自化权：该宫自我膨胀、逞强；
- 自化科：该宫之事物慢慢消散、文过饰非；
- 自化忌：该宫之事物自我损耗、流失，不留。

自化视为「宫位的泄漏」，与生年四化、飞来四化叠加参断。

## 命宫飞四化的总体框架

命宫宫干飞四化，代表命主主动施加于十二宫的意愿与行动方向：

- 命宫化禄入某宫：命主乐于在该宫领域投入、并由此得利；
- 命宫化权入某宫：命主想掌控该宫领域；
- 命宫化科入某宫：命主在该宫领域求名、求稳妥；
- 命宫化忌入某宫：命主在该宫领域付出、执着、放不下——此宫常是命主最挂心之处。

其余十一宫的宫干同理可飞四化，构成「宫位互涉网络」。论断某宫之事，常看：
1. 该宫的生年四化（先天）；
2. 何宫飞化入本宫（谁对此宫施力）；
3. 本宫飞化出何宫（本宫的意愿去向）；
4. 本宫是否自化（自身是否泄漏）。

## 飞星与三合派的配合

实战推演建议：以三合派的星曜组合、庙陷亮度、格局体系定「底盘吉凶」，
再以飞星四化的宫位链路定「事象因果与应期」。两派并非互斥：
星情定性质，飞化定轨迹；格局看强弱，忌入看落点。
